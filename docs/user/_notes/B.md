# Agent B notes for the user manual

- **Admission**: one form creates the student, the permanent student ID (e.g. KSV-26-00417-7), the class place and roll number, the parents/guardians, medical details and emergency contacts. If no emergency contacts are typed, the guardians are used (main contact first).
- **Possible duplicate warning**: shown when a child with a similar name, the same date of birth and a shared parent phone number already exists. Open the existing record, or tick "this is a different child" and give a reason (the reason is recorded).
- **Siblings** appear automatically when two children share a guardian. Choose the existing guardian when admitting a brother or sister.
- **Student ID** never changes. A record entered by mistake is archived (admin), with a reason.
- **Ghana Card numbers** can be typed but are never shown again; only the last 4 digits. An administrator can reveal the full number with a reason (recorded).
- **Emergency View** (phone-friendly): medical alert, allergies, contacts in order with tap-to-call, authorised pickups and recent calls. Every opening is recorded. Log each call's outcome.
- **Class full**: admissions and class changes are refused when a class reaches its capacity; raise the capacity in class settings if appropriate.
- **Promotion**: build a draft for chosen classes, review each student (repeat, skip, withdraw, transfer out, graduate), then commit. With the fee policy set to *block*, students with unpaid fees need a reason before they can move up. A committed promotion can be undone within 14 days (setting) unless later records depend on it (class changes, invoices, attendance or scores in the new year).
- **Withdrawal / transfer**: clearance checklist (fees, books, uniform, property, library). Only the bursar or an administrator clears fees. Completing it changes the student's status and closes the class place. Transfer letters get a number (TL-000001) the first time they are printed.
- **Attendance**: the register opens with everyone present; mark the exceptions and save. If "SMS on absence" is on, the main guardian gets one SMS per absent day.
- **Scores**: class score and exam score are typed out of the level's weights (default 30/70). Once the head locks a term's scores they cannot be changed. Report-card positions show ties as "joint 2nd".
- **Incidents** are visible only to the administrator, the headteacher and the person who wrote them.
