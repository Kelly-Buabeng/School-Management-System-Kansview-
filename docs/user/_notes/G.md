# Agent G notes for the user manual: Imports

- Imports screen: upload an Excel/CSV file, click "Check file" (dry run, nothing saved), fix errors using the
  downloadable error report, decide on possible duplicates (link to existing / create new / skip), then Commit.
- Who: registrar (students and guardians), bursar (opening balances, check only), administrator (everything; the only
  one who can commit).
- Templates with instructions and drop-down lists: Imports → Download template (also in docs/import-templates/).
- Limits: 2,000 rows and 10 MB per file. Commit saves 200 rows at a time and can simply be clicked again after a
  power or network cut; nothing is imported twice.
- Brothers and sisters are linked automatically when their parent has the same phone number on each row.
- Full administrator guide: docs/import-templates/README.md.
