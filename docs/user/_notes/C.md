# Notes for the user manual: Finance (bursar)

- **Fee structures**: build a draft per term and level (copy last term to save time). Only the administrator can activate it. Once active it cannot be edited; make a new one instead.
- **Invoices**: always run "Preview" first. It lists children with problems (no class, no fee structure). Running generation twice never double-bills.
- **Recording a payment**: the reference number is required for everything except cash (type the MoMo transaction ID from the SMS). If the same reference was used before, the system warns you and shows the earlier receipt; continue only if you are sure, and give a reason.
- If the screen says "Not sure it saved", check the payment list before trying again. Trying again with the same form will not create a second payment.
- Receipt numbers never skip. A reversed receipt keeps its number and prints "REVERSED".
- **Reversing a payment**: allowed the same day before the cash-up is closed. After that the administrator must approve it.
- **Overpayments** become credit and are used automatically on the child's next invoice.
- **Discounts, scholarships, waivers**: you request, the headteacher or administrator approves. You cannot approve your own request. Refunds and write-offs need the administrator.
- **Cash-up**: open at the start of the day, close at the end with the counted cash per method; the system shows any difference.
- **Reports**: collections, fees owed by age, defaulters, daily cash-up and reconciliation, each downloadable as Excel or PDF.
