# Notes for the user manual (web app, Agent E)

- Press `/` anywhere to search for a student, parent, staff member or receipt number.
- Emergency View (red button on a student's page) is made for phones. Tap a green "Call" button. After the call, the app
  asks what happened (spoke to them, no answer, message left, wrong number), and the answer is saved in the call log.
- Recording a payment: "Saved" and a receipt number appear only once the server confirms. If the screen says
  "Not sure it saved — check before trying again", press "Check if it was saved". Do not type the payment again and do
  not write a receipt by hand.
- A Mobile Money or bank reference that was already used is flagged in yellow as you type. To save it anyway, give a reason.
- Admission: if the child may already be registered, open the existing record first. To admit anyway, explain why this
  is a different child (the reason is recorded).
- Promotion: preview, set exceptions (each needs a reason and the "Apply" button), confirm, commit. "Undo until …"
  is available for the number of days set in Settings → Policies.
- Attendance: everyone starts as present. Tap only the children who are absent or late, then press "Save register".
- Ghana Card and staff ID numbers are hidden. Only the administrator can reveal them, and must give a reason, which is recorded.
